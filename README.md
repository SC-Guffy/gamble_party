# 우당탕 도박 일주일 — 최대 4인 도박 파티 게임 (서버 버전)

플레이어는 도박꾼. 가진 돈은 단돈 $1000, **일주일(7일)** 동안 가장 많이 불린 사람이 우승합니다.

- **게임 투표**: 매일 낮이 오기 전, 랜덤으로 뽑힌 게임 카드 3장 + **무작위** 중 하나에 투표합니다(15초, 전원 준비하면 바로 마감). 칸별 당첨 확률 = 득표 ÷ 전체 표(아무도 안 찍으면 카드 3장 균등), 무작위가 뽑히면 전체 게임 중 하나. 룰렛이 돌아 결과가 정해집니다.
- **낮**: 투표로 정해진 도박 컨텐츠를 합니다 — 지금은 **경마 / 블랙잭 / 주사위 / 펭귄 빙산 건너기** (`server.js`의 `GAMES`에 하나씩 추가). 게임마다 **베팅 상한**이 있어 올인 즉사는 불가능합니다. 경마 상한 = `$200 + $100 × DAY` (1일차 $300 → 7일차 $900).
- **블랙잭**: 하루 3판, 판당 상한 `$50 + $50 × DAY`. 딜러 공용·플레이어 동시 진행, 딜러는 17 이상 스탠드, 블랙잭 3:2, 더블다운(첫 두 장) 가능, 스플릿/인슈어런스 없음. 단축키 H/S/D.
- **주사위**: 하루 3판, 판당 상한은 블랙잭과 같음. 주사위 2개의 합에 베팅 — 홀/짝 x1.9 · 다운(2~6)/업(8~12) x2.3(7이 나오면 둘 다 꽝) · 더블 x5.7 · 합 단일 지정 x5.7(7) ~ x34.2(2·12). 배당 = `0.95 × 36 ÷ 맞는 경우의 수`(서버가 36가지를 직접 세어 계산). 여러 칸에 나눠 걸 수 있음.
- **펭귄 빙산 건너기**: 하루 3판, 판당 상한은 블랙잭과 같음. 각자 자기 펭귄으로 얼음 조각을 건너며 매번 **더 갈래 / 멈출래**를 고른다. 점프 성공률(머리 위에 표시)은 90% → 85% → … → 45%로 떨어지고, 배당은 `0.95 ÷ (지금까지 성공률의 곱)`(x1.06 → x1.24 → … → 완주 x61.26)이라 어디서 멈추든 기대값이 같다. 실패하면 바다에 풍덩 = 판돈 전액 손실. 단축키 G/스페이스(더 갈래)·S(멈출래).
- **밤**: 정산. 파산($0)한 사람은 **한푼줍쇼를 딱 1번** 누를 수 있고, 누가 말풍선을 눌러 $100을 주면 그걸로 끝. 아무도 안 주면 다음 날은 **아오지 탄광**(게임 참여 불가·관전만)에서 일하고, 그날 밤 정산 때 일당 $200을 받습니다. 모두 "다음 날로"를 누르면 날이 바뀝니다. (구걸해 본 파산자는 자동 준비)
- 7일차 밤이 지나면 시상대에서 최종 순위 발표 → 대기실로 돌아가 새 게임.
- 플레이어 캐릭터는 방 안에서 안 겹치게 상의/하의 색·머리모양·머리색·피부색이 랜덤 배정됩니다. 화면 오른쪽(모바일은 💬 버튼)에 채팅, 말한 내용은 캐릭터 말풍선으로도 뜹니다.

입장: 호스트가 방 제목을 넣고 **방 만들기** → 다른 사람은 타이틀 화면의 **방 목록**에서 눌러 들어옵니다.

`wasd-tori-server`와 같은 구조: 서버가 돈·베팅·경주 결과를 전부 소유하고, 외부 npm 패키지 없이 Node 내장 모듈만 씁니다.

```
server.js       ← 게임 서버 (방/베팅/경주 시뮬레이션/정산)
wsserver.js     ← 작은 WebSocket 구현체 (tori 서버와 동일)
public/index.html ← 클라이언트 (복셀 동물 렌더링 포함)
```

## 실행

```bash
node server.js          # http://localhost:3100  (PORT 환경변수로 변경 가능)
node server.js --check  # 동물 승률표 + 배당/정산 + 상한·파산·탄광 흐름 셀프 체크
DAYS=3 node server.js   # 짧은 판 (일수 변경)
START_MONEY=300 node server.js  # 테스트용: 파산·탄광 흐름을 빨리 보기
GAME=blackjack node server.js   # 테스트용: 그날의 컨텐츠 고정, 투표 생략 (derby | blackjack | dice | penguin)
```

같은 와이파이 친구는 `http://<내 IP>:3100` 으로, 외부 배포는 Render(Web Service, Start Command `npm start`)로 하면 됩니다.

## 동물과 밸런스

| 동물 | 특징 | 기본 승률(8마리 기준) |
|---|---|---|
| 번개(말) | 기복 없는 우등생 | ~20% |
| 깡총이(토끼) | 제일 빠르지만 55% 확률로 중간에 낮잠 | ~16% |
| 뒤뚱이(펭귄) | 배 슬라이딩으로 계속 가속, 미끄덩하면 리셋 | ~14% |
| 쿵쿵이(코끼리) | 발동이 느리지만 최고속도 최상급 | ~13% |
| 꼬꼬(닭) | 가끔 놀라서 푸드덕 폭주 | ~12% |
| 꿀꿀이(돼지) | 출발은 느리고 막판 스퍼트 | ~11% |
| 개굴이(개구리) | 웅크렸다 폴짝, 변동성 최대 | ~8% |
| 엉금이(거북이) | 느림보. 가끔 등껍질 터보(3배속) | ~5% |

- 매판 컨디션(최악~최상, 속도 ±2%)이 랜덤으로 붙고, 그 조건으로 서버가 경주를 3000번 돌려 실제 승률을 구한 뒤 `배당 = 0.92 / 승률`로 정합니다. (환급률 92% → 오래 하면 누군가는 거지가 됩니다)
- 뒤처진 동물은 살짝 빨라져서(러버밴드) 막판까지 접전이 납니다.
- 속도를 바꿨으면 `--check`로 승률표를 다시 확인하세요.
