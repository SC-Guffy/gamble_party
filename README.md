# 뒷방 한탕 — 최대 4인 도박 파티 게임 (서버 버전)

플레이어는 도박꾼. 가진 돈은 단돈 $1000, 방장이 대기실에서 정한 **날수(3·5·7·10·14일, 기본 7일)** 동안 가장 많이 불린 사람이 우승합니다.

- **게임 투표**: 매일 낮이 오기 전, 랜덤으로 뽑힌 게임 카드 3장 + **무작위** 중 하나를 누르면 그게 곧 투표입니다(준비 버튼·제한 시간 없음, 전원이 누르는 순간 추첨. 그 전엔 바꿔 눌러도 됨). 칸별 당첨 확률 = 득표 ÷ 전체 표, 무작위가 뽑히면 전체 게임 중 하나. 룰렛이 돌아 결과가 정해집니다.
- **낮**: 투표로 정해진 도박 컨텐츠를 합니다 — 지금은 **경마 / 블랙잭 / 주사위 / 펭귄 빙산 건너기 / 눈치 숫자 / 인디언 포커 / 미스터리 상자 경매 / 러시안 룰렛 / 풍선 불기 / 도박 코인 단타 / 플링코 / 총잡이 결투** (`server.js`의 `GAMES`에 하나씩 추가, `min`이 있는 게임은 그 인원 이상일 때만 투표에 나옴). 고배당 게임엔 **베팅 상한**이 있어 한 방에 판이 끝나지 않습니다. 대신 **블랙잭·경매·코인은 상한 없음**(가진 돈까지 올인) — 배당이 낮거나(블랙잭 최고 x2.5), 본인이 위험을 조절하거나(코인), 상자 금액이 이미 상한 노릇을 해서(경매). 경마 상한 = `$200 + $100 × DAY` (1일차 $300 → 7일차 $900).
- **블랙잭**: 하루 3판, 판당 상한 없음(칩의 MAX가 "올인 🔥"으로 바뀜). 딜러 공용·플레이어 동시 진행, 딜러는 17 이상 스탠드, 블랙잭 3:2, 더블다운(첫 두 장) 가능, 스플릿/인슈어런스 없음. 사이드벳 **퍼펙트 페어**(처음 두 장이 같은 숫자면 x13, 본 베팅이 있어야 하고 상한은 본 베팅과 합산). 단축키 H/S/D.
- **주사위**: 하루 3판, 판당 상한 `$50 + $50 × DAY`. 주사위 2개의 합에 베팅 — 홀/짝 x1.9 · 다운(2~6)/업(8~12) x2.3(7이 나오면 둘 다 꽝) · 더블 x5.7 · 합 단일 지정 x5.7(7) ~ x15(2·3·11·12). 배당 = `0.95 × 36 ÷ 맞는 경우의 수`(서버가 36가지를 직접 세어 계산), 단 최고 x15로 자른다(합 2·3·11·12는 그만큼 손해 보는 칸). 여러 칸에 나눠 걸 수 있음. 주사위는 하나씩 떨어진다(첫 눈 공개 → 1.8초 뜸 → 두 번째).
- **펭귄 빙산 건너기**: 하루 3판, 판당 상한은 주사위와 같음. 각자 자기 펭귄으로 얼음 조각을 건너며 매번 **더 갈래 / 멈출래**를 고른다. 점프 성공률(머리 위에 표시)은 90% → 85% → … → 55%로 떨어지고(8칸), 배당은 `0.95 ÷ (지금까지 성공률의 곱)`(x1.06 → x1.24 → … → 완주 x13.78)이라 어디서 멈추든 기대값이 같다. 실패하면 바다에 풍덩 = 판돈 전액 손실. 매판 **황금 얼음**이 하나(첫·마지막 칸 제외): 그리로 뛰는 점프는 성공률 반토막, 그 뒤 배당은 두 배(최고 x15로 자름) → 환급률은 그대로. 단축키 G/스페이스(더 갈래)·S(멈출래).
- **눈치 숫자**: 하루 3판, 판당 참가비 `$50 + $50 × DAY` 고정, **3명 이상일 때만** 투표에 나온다. 각자 1~10 중 하나를 몰래 고르고(숫자를 누르면 참가, 다시 누르면 취소·환불), 전원 준비하면 작은 숫자부터 팻말이 뒤집힌다. **남과 안 겹친 숫자 중 가장 작은 걸 고른 사람**이 판돈(이월금 + 참가비 합)의 95% 독식. 전원 겹치면 판돈은 다음 판으로 이월, 그날 마지막 판까지 겹치면 참가자끼리 나눈다. 혼자 참가했는데 이월금이 없으면 무효(환불), 이월금이 있으면 혼자 꿀꺽.
- **인디언 포커** (2인 이상): 하루 3판, 판당 참가비 `$50 + $50 × DAY`(고정). 1~10 카드 두 벌에서 한 장씩 받아 이마에 붙인다 — 남의 카드는 다 보이는데 **내 카드만 못 본다**. 20초 안에 몰래 **콜**(참가비만큼 더 냄) / **다이**를 고르고(시간 초과 = 다이), 공개되면 콜한 사람 중 가장 높은 카드(A=1 < 10)가 판돈의 95%를 가져간다(동점이면 나눔, 아무도 콜 안 하면 참가비 환불). **10을 들고 다이하면 참가비만큼 벌금**이 승자 판돈에 얹힌다. 구경꾼은 모든 카드를 보니 채팅으로 훈수(혹은 블러핑)를 둘 수 있다. 단축키 C/D.
- **미스터리 상자 경매** (2인 이상): 하루 3판, 상자 기준가 `$100 + $100 × DAY`, 입찰 상한 없음(가진 돈까지). 상자 속 금액은 공개된 분포(기준가 × −0.5💣 / 0 / 0.25 / 0.5 / 1 / 1.5 / 3, 확률 6·18·18·20·16·13·9%, 기대값 ≈ 기준가의 74%)에서 뽑히고, 각자 **"이 상자는 $X가 아니다"** 비밀 힌트를 하나씩 받는다(서로 다름). 밀봉 입찰(0 = 패스) → 낮은 순으로 공개 → 최고가 1명만(동점은 추첨) 입찰가를 내고 상자를 가져간다. 수수료는 없고, 기대값보다 비싸게 산 사람이 하우스 몫. **💣 폭탄 상자**를 사면 입찰가에 더해 기준가의 절반을 더 뱉는다(가진 돈까지만). 채팅 블러핑 권장.
- **러시안 룰렛** (2인 이상): 하루 3판, 판당 참가비 고정(`$50 + $50 × DAY`)을 내고 6연발 리볼버(총알 1발)를 돌아가며 자기 머리에 당긴다. 차례마다 **당기기**(빈칸이면 다음 사람, 지금 확률 1/남은 칸) / **넘기기**(참가비의 절반을 판돈에 보태고 같은 칸을 다음 사람에게, 판당 1회) / **연속 2발**(한 차례에 두 번 당김, 판당 1회·남은 칸 3칸 이상, 살아남으면 판돈 몫 두 배). 차례당 12초, 넘기면 자동 당기기. 탕! 맞은 사람은 낸 돈을 전부 잃고 생존자들이 `판돈 × 0.95`를 똑같이 나눈다. 단축키 스페이스(당기기)·P(넘기기)·X(연속 2발).
- **풍선 불기**: 하루 3판, 판당 상한은 주사위와 같음. 모두가 줄을 잡은 공용 풍선이 `x1.00`부터 `e^(0.12·t)`로 부풀고(약 5.8초에 x2, 19초에 x10), 터지기 전에 **놓기**를 누르면 그때 배수(소수 둘째 자리 내림)만큼 받는다. 터지는 배수는 서버가 미리 `0.95 ÷ U`로 뽑아 숨겨 둬서 `P(≥m) = 0.95/m`, 어디서 놓든 기대 환급률 95%(5%는 x1.00에서 바로 펑). 상한 x15(약 23초)에 닿으면 남은 사람은 자동 회수, 못 놓고 터지면 판돈 전액 손실. **👑 최후의 1인**: 터지기 전에 놓은 사람이 2명 이상이면 가장 높은 배수에 놓은 1명이 나머지가 번 돈의 5%를 떼 간다(동점이면 없음). 단축키 스페이스(놓기).
- **도박 코인 단타**: 하루 3판, 투자금 상한 없음(몰빵 가능). 30초 장 동안 서버가 0.25초마다 가격을 만든다(기하 랜덤워크 + 가끔 🚀/📉 뉴스, 한 판에 ~8%로 🌕 투더문 x5 / ☠️ 상장폐지 −99% 초대형 뉴스(1:4라 기댓값 0), 미래 가격은 미리 만들지 않음). 전원 현금으로 시작해 아무 때나 **매수(전액 코인) / 매도(전액 현금)** 토글, 거래마다 수수료 1.5%. 마감 때 들고 있으면 마감가로 강제 매도.
- **플링코**: 하루 3판, 판당 상한은 주사위와 같음. 공이 핀 10줄을 50:50으로 튕기며 내려와 11칸 중 하나에 떨어진다(칸 k 확률 = `C(10,k) ÷ 1024`). 어느 **구역**에 떨어질지 맞히기 — 중앙(칸 4~6, 66%) x1.45 · 외곽(칸 3·7, 23%) x4.05 · 최외곽(칸 0~2·8~10, 11%) x8.69, 빗나가면 꽝. 배당 = `0.95 × 1024 ÷ 그 구역의 경우의 수`(서버가 직접 세어 계산). 매판 끝 칸(0·1·9·10) 중 하나가 **🎰 잭팟 칸**: 최외곽에 걸고 거기 떨어지면 x15, 대신 그 판 최외곽 배당은 x8.06~8.62로 내려 환급률 95%를 맞춘다. 공은 사람마다 하나씩 따로 떨어지고, 경로는 베팅이 잠긴 뒤 서버가 뽑으며 돈은 공이 다 떨어진 뒤에 움직인다.
- **총잡이 결투** (2인 이상): 하루 3판, 판당 참가비 `$50 + $50 × DAY`(고정). 서버가 2.5~7초 중 몰래 정한 순간 **"🔫 쏴!"** 신호가 뜨고, 가장 먼저 쏜 사람이 판돈의 95% 독식(동점이면 나눔). 신호 전에 쏘면 **오발 = 아웃**, 그 전에 가짜 신호(🌭 쏘세지! · 🙏 쏘리! …)가 0~2번 섞인다. 반응 속도는 각자 신호를 받은 순간부터 재서(핑 무관) 서버가 잰 경과 시간과 100ms 하한으로 자른다. 아무도 안 쏘면 오발 안 낸 사람끼리 나누고, 전원 오발이면 하우스 몫. 단축키 스페이스.
- **밤**: 정산. 파산($0)한 사람은 **한푼줍쇼를 딱 1번** 누를 수 있고, 누가 말풍선을 눌러 $100을 주면 그걸로 끝. 아무도 안 주면 다음 날은 **아오지 탄광**에서 일합니다(게임은 관전만). 낮 내내 곡괭이질 미니게임(캐기 버튼/스페이스 연타로 바위를 깨면 돌·은·금·다이아, 깊이 팔수록 비싸짐)을 하고, 그날 밤 일당 = $100 + 캔 돈(최대 $1000)을 받습니다. 성실히 캐면 1분 ~$200 · 3분 ~$400, $1000 근처는 다이아(0.3%)가 터져야 나옵니다 — 파산이 "시작 자금 리셋"이 되지 않게. 모두 "다음 날로"를 누르면 날이 바뀝니다. (구걸해 본 파산자는 자동 준비)
- **사채**: 밤 정산 때 $100씩 빌리고 갚기($100/전액, 가진 돈 한도). 빚(원금+이자) 한도 $1000, 매일 밤 20% 복리(빌린 날 밤은 무이자). 파산해도 빌리면 탄광 면제. 순위·그래프·우승은 순자산(현금 − 빚) 기준.
- 마지막 날 밤이 지나면 시상대에서 최종 순위 발표 → 대기실로 돌아가 새 게임.
- **시상식 칭호**: 최종 결과에서 판마다 쌓인 통계(총 베팅·환수율·최대 한 방/손실·올인·파산·탄광·구걸·적선·게임별 순이익)로 각자 칭호 1~2개(🎰 올인 광, 💎 한탕주의, 🎯 ○○ 장인, 🔥 불사조, 🐢 쫄보…)를 시상대 머리 위에 쾅쾅 찍어 줍니다. 순위 줄을 누르면 통계 카드가 펼쳐집니다.
- **재접속**: 창을 닫거나 새로고침·폰 화면이 꺼져도 자리(돈·베팅·빚·기록)는 📴로 남고, 같은 브라우저로 다시 열면 그대로 이어집니다. 끊긴 동안엔 자동 준비·자동 처리(블랙잭 스탠드, 펭귄 멈춤, 인디언 포커 다이, 룰렛 당기기, 풍선 놓기), 전원이 2분 넘게 끊기면 방이 사라집니다. "방 나가기" 후 다시 들어와도 그때 돈·빚으로 복원됩니다.
- **이모티콘 리액션**: 게임 패널 위(대기실·투표는 왼쪽 아래)의 😀 줄에서 😂 💸 😡 🙏 🔥 👏 😱 🤑 를 누르면 내 캐릭터 머리 위로 튀어 오릅니다 (1인 0.6초 제한, 채팅 로그엔 안 남음).
- 플레이어 캐릭터는 방 안에서 안 겹치게 상의/하의 색·머리모양·머리색·피부색이 랜덤 배정됩니다. 화면 오른쪽(모바일은 💬 버튼)에 채팅, 말한 내용은 캐릭터 말풍선으로도 뜹니다.

입장: 호스트가 방 제목을 넣고 **방 만들기** → 대기실에서 진행 일수를 고르고 시작(시작은 방장만) → 다른 사람은 타이틀 화면의 **방 목록**에서 눌러 들어옵니다.

`wasd-tori-server`와 같은 구조: 서버가 돈·베팅·경주 결과를 전부 소유하고, 외부 npm 패키지 없이 Node 내장 모듈만 씁니다.

```
server.js       ← 게임 서버 (방/베팅/경주 시뮬레이션/정산)
wsserver.js     ← 작은 WebSocket 구현체 (tori 서버와 동일)
public/index.html ← 클라이언트 (복셀 동물 렌더링 포함)
```

## 실행

```bash
node server.js          # http://localhost:3100  (PORT 환경변수로 변경 가능)
node server.js --check  # 동물 승률표 + 배당/정산 + 상한·파산·탄광 흐름 셀프 체크
DAYS=3 node server.js   # 새 방의 기본 일수 변경 (대기실에서 방장이 바꿀 수 있음)
START_MONEY=300 node server.js  # 테스트용: 파산·탄광 흐름을 빨리 보기
GAME=blackjack node server.js   # 테스트용: 그날의 컨텐츠 고정, 투표 생략 (derby | blackjack | dice | penguin | nunchi | indian | auction | watergun | balloon | coin | plinko | duel)
```

같은 와이파이 친구는 `http://<내 IP>:3100` 으로, 외부 배포는 Render(Web Service, Start Command `npm start`)로 하면 됩니다.

## 동물과 밸런스

| 동물 | 특징 | 기본 승률(8마리 기준) |
|---|---|---|
| 번개(말) | 기복 없는 우등생 | ~20% |
| 깡총이(토끼) | 제일 빠르지만 55% 확률로 중간에 낮잠 | ~16% |
